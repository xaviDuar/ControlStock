# Crear Rótulos

La pantalla **Crear Rótulos** te permite elegir productos, asignarles su fecha de elaboración y su condición de conservación, y armar la lista de etiquetas de vencimiento a generar.

## Qué ves en la pantalla

- El título **Crear Rótulos** y una descripción de uso.
- Una **barra de búsqueda** para filtrar los productos.
- A la derecha del buscador, un botón **+** para agregar un rótulo nuevo.
- La lista de **productos disponibles** (solo los que tienen stock en el inventario).
- A la derecha, la **Lista para rótulos** (el carrito).

## Elegir un producto y su condición

Cada producto muestra sus métodos de conservación: **Refrigerado**, **Congelado**, **Bodega** y **Toppinera**. Para cada método que tenga condiciones, hay un selector donde elegís la condición de vencimiento (por ejemplo, "72 HS (bolsa cerrada)" o "Fin del día").

- Si el producto no tiene condiciones, muestra "Sin condiciones de vencimiento".

## Cargar la fecha de elaboración

En cada producto hay un campo de **fecha de elaboración**. Al cargarla, al lado del selector aparece la fecha de vencimiento calculada al instante (`→ vence …`).

## Agregar a la lista

Tocá el botón **+ Agregar** para sumar el producto a la **Lista para rótulos**.

- Si no cargaste la fecha, aparece un aviso pidiéndola y no se agrega nada.
- Si ese producto con esa fecha ya está en la lista, aparece un aviso y no se agrega nada.
- Si todo está bien, el producto aparece en la lista y la fecha se limpia para poder cargar otro.

## Agregar un rótulo nuevo (botón +)

El botón **+** (arriba a la derecha del buscador) sirve para hacer un rótulo de un producto que todavía no está cargado o que es una excepción. Al tocarlo se abre una ventana que te pide:

- **Nombre del producto**.
- **Fecha de elaboración**.
- **Cantidad** de rótulos.
- **Fecha de vencimiento** (la cargás a mano).

Este rótulo **no se guarda**, solo se genera. Al completar los datos, se agrega a la **Lista para rótulos**.

## La Lista para rótulos

En la lista se acumulan los productos elegidos. Cada ítem muestra:

- El nombre del producto.
- La fecha de elaboración.
- Las condiciones elegidas por método.

Podés quitar un ítem tocando la **X**. Al pie se muestra cuántos productos hay seleccionados y el botón **Crear Rótulos** para generar las etiquetas.
