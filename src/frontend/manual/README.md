# Manual de usuario — ¿Cuándo Vence?

Este manual describe las pantallas del sistema **¿Cuándo Vence?** y qué se puede hacer en cada una.

## Pantallas

- [**Portada y acceso**](./portada.md) — la pantalla inicial con el formulario de inicio de sesión.
- [**Home**](./home.md) — la pantalla principal con accesos directos y resumen del local.
- [**Inventario**](./inventario.md) — los lotes de producto con su estado de vencimiento.
- [**Crear Rótulos**](./rotulos.md) — para generar las etiquetas de vencimiento.
- [**Productos**](./productos.md) — el catálogo de productos con sus reglas de vencimiento.
- [**Conteo**](./conteo.md) — para anotar lo que quedó al final del día y la mercadería que entra.
- [**Estadísticas**](./estadisticas.md) — gráficos de ganancias, desperdicio y uso del inventario.
